# V98 — Product description formatting fix

- Fixes the nested description placeholder that was being removed by the renderer.
- Renders the full product description instead of truncating it at the first blank line.
- Preserves paragraph breaks and supports Markdown-style headings, bullets, numbered lists, and HTML line-break separators as plain text.
- Converts common inline checkmark lists and "Isme kya milega" labels into readable sections.
- Adds mobile-friendly spacing and line-height for description content.

No checkout, Cashfree, order, coupon, pricing, countdown, sticky purchase bar, product API, or admin business logic was changed.
